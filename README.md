# GSAP Reference

A personal library of custom GSAP snippets built across client projects.
Each snippet is self-contained, annotated, and ready to adapt.

## Structure

```
snippets/
└── dropdown-stagger.js
```

## Usage

Snippets are written as vanilla JS and assume GSAP is already loaded on the page.
Copy the snippet, drop it after your GSAP script tag, and tune the values to fit your project.

## Snippets

| File | Description |
|------|-------------|
| `dropdown-stagger.js` | Stagger reveal animation for Webflow dropdown list items on open |
